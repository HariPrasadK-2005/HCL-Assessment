# HCL Assessment – Core Java Checkpoint

## About
This repository contains my solutions to the HCL Core Java Checkpoint assessment, focusing on Object-Oriented Programming (OOP) concepts in Java.

I completed 10 programming problems by implementing the required concepts and testing the solutions with different inputs.

## Topics Covered
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding
- Method Overloading
- Abstraction
- Interfaces
- Abstract Class
- Runtime Polymorphism
- Constructors

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/HariPrasadK-2005/HCL-Assessment.git
   ```
2. Open the project folder.
3. Compile a Java file:
   ```bash
   javac FileName.java
   ```
4. Run the program:
   ```bash
   java ClassName
   ```

Replace `FileName` and `ClassName` with the appropriate Java filename and public class name.
